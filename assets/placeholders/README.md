## Drawn diagrams

Not photographs, and not from Pexels. Added 2026-10-23 for the before/after compare (0038) and the scroll reveals (0039). Each file is stamped “PLACEHOLDER” and “NOT A REAL PHOTO”. The before and after files share the house, the clouds, and the stamp so a slider seam does not jump; only the yard changes. Use them when a picture has to be obviously fake. Do not use them as a stand-in for a finished project.
